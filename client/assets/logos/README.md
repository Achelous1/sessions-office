# Agent marks

These assets identify the service used by a session. They are not Session Office branding or an endorsement.

- `claude.png`: Claude's tray mark, from the official Claude desktop app (`TrayIconTemplate@3x.png`). Claude and its mark belong to Anthropic. [Anthropic legal information](https://www.anthropic.com/legal).
- `chatgpt.svg`: OpenAI's Blossom mark, from the official ChatGPT desktop app (`openai_logo_regular_bounding_box`). ChatGPT and the Blossom belong to OpenAI. [Brand guidelines](https://openai.com/brand/).

The marks retain their original geometry. They are excluded from this repository's Unlicense dedication. CSS uses their alpha masks so they remain legible in both themes; the ChatGPT mark is monochrome.

The code-built blue character in `client/js/characters/codex-companion.js` is a voxel interpretation of the default Codex companion. Its visual reference was the official desktop app's `codex-spritesheet-v6`; that sprite sheet is not redistributed here.
